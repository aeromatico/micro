WordPress: Apariencia → Editor de temas → header.php (o con un plugin como "Insert Headers and Footers"), pegalo justo antes de </head>.

Sitio HTML plano: pegalo antes de </head> en cada página donde quieras el chat (o en el template/layout compartido, si tu sitio usa uno).

Otros armadores (Wix, Shopify, Squarespace, etc.): buscá la opción "Código personalizado" / "Custom code" / "Insertar en <head>" en la configuración del sitio y pegalo ahí.

El chat aparece solo, como una burbuja flotante — no hace falta tocar nada más del sitio.
