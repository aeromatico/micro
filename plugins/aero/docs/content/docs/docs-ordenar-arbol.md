# Función: Ordenar árbol

**Ruta:** `Docs → Ordenar árbol`
**Controlador:** `Aero\Docs\Controllers\Categories`
**Permiso:** `aero.docs.manage`

Muestra el árbol completo de categorías para **reordenarlas arrastrando**. Es la
forma más rápida de ajustar la navegación del centro de ayuda.

## Cómo se usa

- **Arrastra** una categoría para subir/bajar su posición entre hermanas.
- **Anida**: suelta una categoría dentro de otra para convertirla en hija.
- El nuevo orden se refleja de inmediato en el centro de ayuda (sidebar y
  navegación).

> [!NOTE]
> El orden de las categorías define también el **orden de lectura** del centro
> de ayuda (anterior/siguiente entre artículos).

> [!TIP]
> Reordena primero las categorías raíz y después sus hijos: es más fácil ver la
> estructura de arriba hacia abajo.
