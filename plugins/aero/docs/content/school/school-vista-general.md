# Colegio

**Ruta:** `/backend/aero/school/dashboard` · **Permiso:** `aero.school.use`

Gestión de un colegio en Bolivia: estudiantes, apoderados, cobro de matrícula y pensiones con recordatorios por WhatsApp, asistencia con aviso, calificaciones y boletín en PDF, comunicados y reportes de morosidad.

## Menú

| Entrada | Para qué sirve |
| --- | --- |
| **Panel** | Resumen del colegio. |
| **Estudiantes** | Alumnos y su curso. Un alumno nuevo recibe de inmediato las cuotas de los conceptos de su curso. |
| **Apoderados** | Responsables de cada estudiante. |
| **Cursos** | Los cursos del colegio. |
| **Asistencia** | Registro de asistencia, con aviso. |
| **Calificaciones (próx.)** | Calificaciones y boletín en PDF. |
| **Cobrar** | Registrar el pago de cuotas. |
| **Cuotas** | Las cuotas generadas. |
| **Pagos y recibos** | Pagos recibidos y sus recibos. |
| **Pensiones y matrícula** | Precios de la matrícula y de las pensiones. |
| **Otros cobros** | Planes de cobros adicionales. |
| **Comunicados** | Avisos a apoderados. |
| **Reportes** | Reportes, incluida la morosidad. |
| **Gestiones** | Años escolares. |
| **Configuración** | Ajustes del colegio. |

## Cobranza

- Los recordatorios de cobro por WhatsApp salen de un proceso diario (09:00).
- Si pagas con QR (Bolivia Pay), el pago de una cuota se registra de inmediato; además hay una revisión cada cinco minutos como respaldo.

> [!NOTE]
> El portal público del colegio solo se muestra si el colegio está activado en Configuración y ya tiene estudiantes.
