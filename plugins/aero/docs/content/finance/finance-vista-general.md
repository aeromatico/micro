# Finanzas — vista general

Finanzas registra los **ingresos y egresos** de tu negocio y los lleva a un **libro diario** y **libro mayor** con partida doble, usando un plan de cuentas boliviano.

**Menú:** Finanzas · **Permiso:** `aero.finance.use`

## Qué incluye

| Sección | Para qué sirve |
|---|---|
| Ingresos y egresos | Registrar cada cobro o pago ([detalle](finance-movimientos)) |
| Caja chica | Fondos con arqueo ([detalle](finance-caja-chica)) |
| Libro diario | Asientos generados, uno por movimiento |
| Libro mayor y reportes | Mayor por cuenta y sumas y saldos |
| Plan de cuentas | Cuentas disponibles para categorizar |
| Configuración | Interruptor general y registros automáticos ([detalle](finance-configuracion)) |

## Cómo funciona

- Cada movimiento genera un asiento de partida doble automáticamente.
- Tu contabilidad es **independiente**: cada negocio tiene sus propios libros. No ves los de otros tenants ni los del portal.
- Las ventas de la tienda, del POS y las membresías del gimnasio se pueden registrar solas (ver Configuración).

> [!NOTE]
> Con el sistema apagado en Configuración no se registra nada, pero los libros se conservan para consulta.

**Versión documentada:** 1.3.0
