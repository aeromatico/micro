# Configuración de Finanzas

**Ruta:** Finanzas → Configuración · **Modelo:** `FinanceSettings` · **Permiso:** `aero.finance.use`

| Campo | Por defecto | Efecto |
|---|---|---|
| Sistema activo | Sí | Apagado: no se registra nada (manual ni automático). Los datos se conservan |
| Registrar automáticamente | Sí | Interruptor general de registros automáticos |
| Ventas de la tienda y POS | Sí | Asienta cada venta pagada y cada reembolso |
| Cobros del portal (planes y créditos) | Sí | Solo aplica al libro del portal, no al de un tenant |
| Membresías del gimnasio | Sí | Asienta los pagos de membresías |

> [!NOTE]
> Cada negocio tiene su propio libro. Estas opciones afectan solo al tuyo.

**Versión documentada:** 1.3.0
