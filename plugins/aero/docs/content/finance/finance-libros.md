# Libros, reportes y plan de cuentas

**Menú:** Finanzas · **Permiso:** `aero.finance.use`

- **Libro diario** (Finanzas → Libro diario): lista los asientos de partida doble, uno por movimiento.
- **Libro mayor y reportes** (Finanzas → Libro mayor y reportes): mayor por cuenta y balance de sumas y saldos.
- **Plan de cuentas** (Finanzas → Plan de cuentas): cuentas contables bolivianas.

## Cuenta contable (Plan de cuentas)

| Campo | Obligatorio | Descripción |
|---|---|---|
| Código | Sí | Ej. 5.2.07 |
| Nombre | Sí | |
| Tipo | Sí | Clase de cuenta |
| Activa | No | Activa por defecto |

> [!TIP]
> Las cuentas que crees aquí aparecen como opciones de **Categoría** al registrar un [ingreso o egreso](finance-movimientos).

**Versión documentada:** 1.3.0
