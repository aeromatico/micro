# Atajos · Vista general

Los **atajos** son botones rápidos que armas tú mismo para tu dashboard: abren una lista, un formulario «Nuevo» o una dirección web que uses a diario.

**Ruta:** `Atajos → Mis atajos`
**Permiso:** `aero.shortcuts.use`

## Cómo se usa

1. Entra a **Atajos → Mis atajos** y pulsa **Nuevo** (ver [Mis atajos](shortcuts-mis-atajos)).
2. En el dashboard, agrega el widget **Atajos (botones rápidos)** para mostrar tu fila de botones.
3. Arrastra los botones para cambiar su orden.

> [!NOTE]
> Cada tenant tiene sus propios atajos; nadie más los ve. Solo aparecen pantallas a las que tu usuario tiene acceso.

**Versión documentada:** 1.1.0
