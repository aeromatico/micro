Qué puedes pedirle a tu IA

Una vez conectada, habla en tu idioma. Ella elige las herramientas y tú ves qué hizo.

Conéctalo en 2 minutos

  1. En el panel abre API & MCP → Keys MCP y crea una key: elige tenant, módulos y fecha de expiración.
  2. Guárdala en la variable de entorno MARKET_MCP_KEY (solo se muestra una vez).
  3. Pega la configuración de tu cliente.
